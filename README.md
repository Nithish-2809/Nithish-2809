### ElectricSearch
**Offline-first desktop search engine** built on Electron.js — indexes 1,000+ images via OCR and returns full-text and semantic search results without any cloud dependency.

- Multi-threaded OCR pipeline using Node.js Worker Threads — **+56% throughput**
- Offline semantic search with `Xenova/bge-small-en-v1.5` (384-dim embeddings, cosine similarity), 40–60ms retrieval
- SQLite FTS5 indexing delivering **8–12ms** full-text search
- Secure architecture: 25+ IPC APIs, preload scripts, context isolation

`Electron.js` `React.js` `Node.js` `SQLite FTS5` `Tesseract OCR` `Transformers`
